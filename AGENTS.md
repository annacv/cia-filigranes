# Agent guide — Cia Filigranes

## Adding a new show

When asked to add, introduce, or promote a new show (espectacle), **read and follow**:

[`docs/adding-a-new-show.md`](docs/adding-a-new-show.md)

That spec covers both modes (full home promo vs catalog item only), required assets, file counts, components involved, and the step-by-step checklist. Do not improvise a parallel registration path — `ROUTES_INDEX` in `constants/index.ts` is the source of truth for show order across nav, footer, highlights, hire forms, and downloads.

Image work for a new show (JPEG → WebP conversion and optimization) is documented in [`docs/adding-new-images.md`](docs/adding-new-images.md); the show spec points there at the assets step.
